🎁 Wie funktioniert's?

Ein Baum für alle: Jede Person weltweit, die diese Seite geöffnet hat, gießt denselben Baum. Jeder Gieß-Erfolg lässt den Baum für alle sichtbar wachsen (0–100) – ihr seht das Wachstum live und animiert vor euch geschehen.

Cooldown: Nach jedem Gießen müssen 4 Stunden vergehen, bevor irgendjemand erneut gießen darf.

Achtung, Verfall: Sofort nach dem Gießen startet ein 12-Stunden-Timer. Innerhalb dieser Zeit muss – sobald der 4-Stunden-Cooldown vorbei ist – erneut gegossen werden. Der Countdown ist durchgehend sichtbar und färbt sich in den letzten 2 Stunden rot. Läuft er komplett ab, verwelkt der Baum vollständig und bleibt in seiner aktuellen Größe als kahler, toter Baum stehen, bis ihn jemand wieder gießt und er als kleiner Sämling neu zu wachsen beginnt.

🌿 Pflegen: Der grüne Knopf neben der Gießkanne verkürzt den aktuellen Gieß-Cooldown sofort um 15 Minuten – nützlich, wenn es knapp wird. Einmal pro Stunde nutzbar.

Live-Chat: Links könnt ihr euch kurze Nachrichten (max. 60 Zeichen) schreiben – sichtbar für alle, die gerade online sind.

📖 Setup-Anleitung: Lokal starten & Firebase in 2 Minuten einrichten

1. Lokal starten: Diese index.html einfach doppelt anklicken oder mit einem lokalen Server öffnen (z. B. npx serve . oder VS-Code-Erweiterung "Live Server"). Ein echter Server ist empfehlenswert, damit ES-Module (Firebase) sauber laden.

2. Firebase-Projekt anlegen (kostenlos, ~2 Minuten):

1. Gehe zu https://console.firebase.google.com
2. "Projekt hinzufügen" → Namen vergeben → erstellen
3. Im Menü links: "Build" → "Firestore Database" (NICHT Realtime Database!)
   → "Datenbank erstellen" → Standort wählen → Modus "Testmodus"
4. Im Menü links: Zahnrad ⚙️ → "Projekteinstellungen"
5. Unten bei "Meine Apps" → Web-App ( Symbol) hinzufügen
   → einen Namen vergeben → "App registrieren"
6. Das angezeigte firebaseConfig-Objekt kopieren

3. Konfiguration eintragen: Suche im Code (Strg+F) nach DEIN_API_KEY und ersetze das komplette firebaseConfig-Objekt durch das kopierte aus Schritt 2.

4. Firestore-Sicherheitsregeln: Im Firebase-Menü "Firestore Database" → Tab "Regeln" folgendes eintragen und veröffentlichen. Wichtig: Diese Version enthält jetzt zusätzlich Regeln für Chat, Online-Anzeige und die Minispiel-Highscores – falls du vorher schon andere Regeln eingetragen hattest, ersetze sie komplett durch diese hier:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    match /christmasTree/global {
      allow read, write: if true;
    }

    match /christmasTreeChat/{messageId} {
      allow read: if true;
      allow create: if request.resource.data.text is string
                    && request.resource.data.text.size() > 0
                    && request.resource.data.text.size() <= 60
                    && request.resource.data.nick is string
                    && request.resource.data.nick.size() <= 60;
      allow update, delete: if false;
    }

    match /christmasTreePresence/{clientId} {
      allow read, write: if true;
    }

    match /christmasTreeHighscores/{scoreId} {
      allow read: if true;
      allow create: if request.resource.data.name is string
                    && request.resource.data.name.size() > 0
                    && request.resource.data.name.size() <= 12
                    && request.resource.data.score is number;
      allow update, delete: if false;
    }

    match /christmasTreeSlingshotScores/{scoreId} {
      allow read: if true;
      allow create: if request.resource.data.name is string
                    && request.resource.data.name.size() > 0
                    && request.resource.data.name.size() <= 12
                    && request.resource.data.score is number;
      allow update, delete: if false;
    }

    match /christmasTreeFlappyScores/{scoreId} {
      allow read: if true;
      allow create: if request.resource.data.name is string
                    && request.resource.data.name.size() > 0
                    && request.resource.data.name.size() <= 12
                    && request.resource.data.score is number;
      allow update, delete: if false;
    }
  }
}

Hinweis: Diese offenen Regeln sind bewusst simpel gehalten für ein Spaß-Projekt ohne Login. Der Chat-Filter (Wortliste + Spam-Erkennung) läuft nur clientseitig in der Seite selbst – wer die Firestore-API direkt anspricht, könnte ihn umgehen (das gilt auch fürs Minispiel: die Punktzahl wird clientseitig berechnet und ungeprüft gespeichert). Für den produktiven Einsatz solltest du serverseitige Validierung (z. B. Cloud Functions) ergänzen, damit niemand den Cooldown umgeht oder Fantasie-Highscores einträgt.

5. Mystery-Geschenk-Video (optional): Suche im Code nach DEINE_YOUTUBE_VIDEO_ID und ersetze sie durch die ID deines Wunschvideos – das ist der Teil der YouTube-URL nach watch?v= (z. B. bei youtube.com/watch?v=ABC123xyz wäre die ID ABC123xyz). Lässt du das Feld leer/als Platzhalter, zeigt der Kasten bei Stufe 100 stattdessen einen freundlichen Hinweis.

6. Flappy Weihnachten personalisieren (optional): Suche im Code nach MG3_CHARACTER und MG3_PASS_MESSAGES/MG3_CRASH_MESSAGES – dort lässt sich der Charakter ('santa', 'grinch', 'reindeer' oder 'emoji' mit eigenem Zeichen) und die Sprüche beim Passieren eines Hindernisses bzw. beim Abstürzen frei anpassen, z. B. für eigene Insider-Witze oder Abschiedswünsche.

7. Fertig! Datei speichern, neu laden – Baum, Chat, Online-Anzeige, Geschenk und alle drei Minispiele synchronisieren sich jetzt live über alle geöffneten Browser-Fenster/Geräte hinweg.

Neu: Ein 🎮-Button oben rechts öffnet das Minispiel "Geschenke fangen" – 60 Sekunden lang mit der Maus/dem Finger einen Sack steuern, Geschenke einsammeln (+Punkte), Kackhaufen ausweichen (−Punkte). Ein 🎯-Button öffnet "Kopf-Ziel: Zwille" – ebenfalls 60 Sekunden, mit der Zwille auf den grün-grummeligen Unruhestifter zielen (+Punkte), Weihnachtsmann/Elfen/Rudolph aber verschonen (−Punkte bei Treffer). Ein 🐦-Button öffnet "Flappy Weihnachten" – Klick/Tap/Leertaste zum Fliegen, Schornsteine/Geschenke-Türme/Kerzen ausweichen, mit anpassbaren Sprüchen beim Passieren und Abstürzen. Alle drei haben eigene Highscore-Listen: Top 5 kompakt unter den Minispiel-Buttons, Top 10 im jeweiligen Fenster. Namen sind auf 12 Zeichen (Buchstaben/Zahlen) begrenzt.

Neu: Alle paar Minuten fliegt ein Schlitten mit Rentieren (Rudolph vorneweg mit leuchtender Nase) über den Himmel. Am 31.10. schaltet die Seite automatisch in einen spukigen Look um (eigene, nicht-lizenzierte Gestaltung) – dann fliegt statt Rudolph ein Geisterhund mit einer Kürbis-Sleigh, der Baum trägt statt des Sterns einen leuchtenden Kürbis, und über dem Mond erscheint beim Hovern ein gruseliges Gesicht. Das Gießfeld oben ist fest unter dem Titel verankert.

Technik: PixiJS (Rendering), Firebase Firestore (onSnapshot + Transaktionen für Echtzeit-Sync ohne Backend), Web Audio API (synthetisierte Musik & Sounds). Die Online-Zählung nutzt einen einfachen Heartbeat-Mechanismus (alle 20s ein "Ich bin noch da"-Signal je Client) statt einer echten Presence-API, da Firestore diese nicht nativ mitbringt. Baum, Landschaft und Schnee sind vollständig prozedural gezeichnete Vektorgrafik – kein Bild-Asset nötig. Zum Testen einzelner Wachstumsstufen kann in der Browser-Konsole redrawTree(100) eingegeben werden – das ändert nur die lokale Ansicht, nicht die geteilten Daten.
